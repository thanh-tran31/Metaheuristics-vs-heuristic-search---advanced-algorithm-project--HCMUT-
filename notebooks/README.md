# Visualizations & Statistical Analysis

Thư mục chứa Jupyter Notebooks phục vụ phân tích dữ liệu và vẽ đồ thị.

## Nội dung
- Biểu đồ hội tụ Cost - Time.
- Đồ thị log-log runtime theo kích thước bản đồ.
- Phân tích độ nhạy tham số (Ablation study).
- Kiểm định thống kê phi tham số (Wilcoxon signed-rank / Mann-Whitney).
