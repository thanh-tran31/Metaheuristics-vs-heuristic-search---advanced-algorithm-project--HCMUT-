# Benchmark Datasets

Thư mục lưu trữ dữ liệu thực nghiệm từ MovingAI Grid Benchmark.

## Cấu trúc
- `maps/`: Chứa các tệp lưới bản đồ 2D (`.map`), tối thiểu 2 bản đồ.
- `scenarios/`: Chứa các tệp kịch bản kiểm thử (`.scen`) định nghĩa tọa độ Start và Goal chuẩn.

## Nguồn dữ liệu
- Tham khảo và tải về từ: [MovingAI Grids Benchmark](https://movingai.com/benchmarks/grids.html)
