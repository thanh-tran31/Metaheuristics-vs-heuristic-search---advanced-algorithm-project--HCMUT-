# Unit Tests

Thư mục chứa các ca kiểm thử tự động (Unit Test).

## Kiểm thử trọng tâm
- Kiểm tra tính chính xác của hàm heuristic (tính admissible và consistent).
- Kiểm tra tính đúng của thuật toán Line-of-Sight trong các góc cản.
- Kiểm thử các cấu trúc dữ liệu ưu tiên (Min-Heap) và cơ chế tránh vật cản.
