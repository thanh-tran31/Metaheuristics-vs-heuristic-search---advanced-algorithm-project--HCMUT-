# Metaheuristics-vs-heuristic-search---advanced-algorithm-project--HCMUT-
Benchmarking Metaheuristics vs. Heuristic Search algorithms in 2D pathfinding problems

Run correctness checks with `python run_tests.py` and the smoke comparison with
`python -m experiments.benchmark`. The [experiment guide](experiments/README.md)
covers the full profile, output locations and interpretation.
