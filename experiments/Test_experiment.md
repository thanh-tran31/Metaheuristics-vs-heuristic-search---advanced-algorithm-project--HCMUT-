## 3. Kiểm tra dữ liệu đầu vào

Có thể chạy những assertion sau sau khi khai báo dữ liệu ở mục 2:

```python
assert len(grid) == 32
assert all(len(row) == 32 for row in grid)
assert all(cell in (0, 1) for row in grid for cell in row)
assert sum(cell == 0 for row in grid for cell in row) == 819
assert sum(cell == 1 for row in grid for cell in row) == 205
assert grid[start[1]][start[0]] == 0
assert grid[goal[1]][goal[0]] == 0
```

## 4. Cách sử dụng khi test thuật toán

Mỗi thuật toán nhận cùng ba tham số và trả về `path` hoặc `None`:

```python
# Ví dụ: thay `solve` bằng hàm của A*, Theta* hoặc ACO.
path = solve(grid, start, goal)

assert path is not None, "Thuật toán chưa tìm được đường đi"
assert path[0] == start
assert path[-1] == goal
```

Nếu cần tính độ dài từ các waypoint của `path`:

```python
from math import dist, isclose


def path_length(path):
    return sum(dist(a, b) for a, b in zip(path, path[1:]))


length = path_length(path)
print("Path length:", length)

# Chỉ áp dụng kiểm tra tối ưu này cho A* chuẩn trên cùng grid
# và cùng quy tắc 8 hướng, không cắt góc:
# assert isclose(length, optimal_grid_length, abs_tol=1e-6)
```

**Quan trọng:** Trước khi kiểm tra độ dài, bộ test cần **validate từng đoạn của path**: A*/ACO chỉ được đi sang ô lân cận hợp lệ, còn Theta* có thể nối các waypoint xa nhau nhưng phải có Line-of-Sight. Hàm `path_length()` tự nó không phát hiện đường đi xuyên vật cản. Với Theta*, `optimal_grid_length` không phải nghiệm tối ưu cho bài toán any-angle; với ACO, không bắt buộc luôn đạt tối ưu.
